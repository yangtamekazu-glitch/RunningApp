# RunRoute - ランニングコース自動生成アプリ
🏃‍♂️ **指定した距離に合わせて、走りやすい最適なルートを自動生成するWebアプリ**

## 📝 概要
「いつものコースに飽きた」「今日は◯km走りたいけど、どういう道順で走ればいいか分からない」というランナーの悩みを解決するアプリです。
スタート地点とゴール地点（および任意の経由地）を指定し、目標とする走行距離を入力すると、Google Maps APIを活用して目標距離を満たす迂回ルートを自動で計算・提案します。幹線道路を避けた「徒歩ルート」をベースにするため、車通りが少なく走りやすい道が選ばれやすくなっています。

## ✨ 主な機能
- **直感的なマップ操作:** Googleマップ上をクリックするだけで、スタート・ゴール・経由地（最大5ヶ所）を簡単に設定できます。
- **現在地取得機能:** GPSを利用し、ワンタップで現在地をスタート地点に設定可能です。
- **自動距離調整アルゴリズム:** スタートとゴールの直線距離が目標距離に満たない場合、自動的に楕円状の迂回ウェイポイントを計算し、目標距離を越えるルートを生成します。
- **Googleマップ連携:** 生成したルートを本家のGoogleマップ（アプリ・ブラウザ）でそのまま開き、ナビゲーションを開始することができます。
